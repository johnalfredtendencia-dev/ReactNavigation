## Final Verification

Before submitting, verify:

1. **GitHub Repository:**
   - [ ] Open repository in browser (incognito/private mode)
   - [ ] Verify all files are visible
   - [ ] Test cloning: `git clone <your-repo-url>`
   - [ ] Confirm README displays correctly

2. **Lab Report:**
   - [ ] Open PDF to verify it's not corrupted
   - [ ] Check all images are visible
   - [ ] Verify all pages are included
   - [ ] Confirm file size is reasonable (< 20 MB)

3. **Code Functionality:**
   - [ ] Clone your repo to a different folder
   - [ ] Run `npm install`
   - [ ] Run `npm run android`
   - [ ] Verify it works from fresh install

---

## Common Mistakes to Avoid

❌ **Don't:**
- Submit without testing first
- Include node_modules in repository
- Use placeholder text in README
- Submit corrupted or empty files
- Forget to add student information
- Submit late without prior communication
- Copy code without attribution
- Include sensitive information (API keys, passwords)

✅ **Do:**
- Test everything before submitting
- Use .gitignore properly
- Fill out all documentation
- Verify all files are uploaded
- Include your name and ID everywhere
- Submit on time
- Write your own code
- Keep credentials in environment variables
